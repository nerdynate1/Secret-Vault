# Secret-Vault
Implement a secret vault in java

This is a project code where I create a secret vault in java that allows the user to 
• Add a new service name, username, and password triple.
• Lookup a user name-password pair for a given website.
• Add a new service name and user name with a randomly generated password of a
specific length.
• Add a new service name and private key pair.
• Lookup an Elgamal private key given a service name and output as a Base64 encoded
string.
• Add a new service name and private key with a freshly generated 512-bit Elgamal key
pair (the public key should be output to the screen as a Base64 string).
